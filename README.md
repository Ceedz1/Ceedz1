### 👋 Hey there, I'm Christian

I'm a **fresh BSIT graduate** from Cebu, Philippines, building my path as a full-stack developer. I specialize in the **MERN stack with TypeScript** and love crafting web apps that are both functional and well-designed.

My capstone project, **SubaCares**, is a real-world health information management system deployed for a barangay health center in Lapu-Lapu City — built with React, Node.js, Express, MySQL, and Prisma.
